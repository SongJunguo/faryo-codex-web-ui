# Faryo 1.11.4

Faryo 1.11.4 restores chronological activity and question navigation for long
Codex App Server conversations.

- Every visible user message now has a distinct, privacy-safe question identity,
  even when Codex retains several follow-ups inside one protocol turn.
- Commands, file changes, searches and tools are grouped as contiguous timeline
  batches. Interim assistant output starts a new batch, so current work remains
  visible instead of being moved into an old oversized Activity card.
- Browser-issued command rows anchor to the exact visible item present when the
  command starts. Legacy turn anchors move before the newest conversation segment
  rather than remaining pinned to the live tail.
- Owner recovery consults durable rollout activity only for sessions rehydrated
  after a restart. In-memory message digests align recovered activity and are
  removed before the authenticated history response is returned.
- Regression coverage includes multi-message protocol turns, durable recovery,
  command chronology, question navigation, ordinary reload and the real browser
  activity surface.

This patch does not change Codex execution, message delivery, authentication,
tmux geometry or the independent App Server process lifetime.
