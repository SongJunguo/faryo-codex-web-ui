# Faryo 1.11.2

Faryo 1.11.2 fixes a mobile-width regression in the history-session resume
sheet.

- The directory sheet now opts out of the CSS Grid automatic minimum size, so
  longer resume copy cannot widen the sheet beyond the visual viewport.
- Backend, context-window, folder and action controls remain fully visible at
  narrow mobile widths without reducing the user's configured text size.
- The real Gateway browser smoke now asserts that the resume sheet itself fits
  inside the visual viewport; checking the page behind the fixed sheet is no
  longer considered sufficient.

No Codex runtime, authentication, Owner, App Server, or tmux behavior changes in
this patch.
