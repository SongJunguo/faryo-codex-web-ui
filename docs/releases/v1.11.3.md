# Faryo 1.11.3

Faryo 1.11.3 fixes the chronology of browser-issued Codex command rows.

- Codex TUI commands now record the latest durable conversation-turn key when
  they begin, using the same identity as paged history.
- A command whose anchored history page is not loaded is no longer appended to
  the live tail. It appears when its actual page is loaded instead.
- Legacy command rows without an anchor are placed before the currently loaded
  conversation rather than remaining permanently below every newer reply.
- Regression tests cover stable TUI anchors, missing history pages, and legacy
  unanchored events.

This patch does not change Codex command execution, transcript content, tmux
geometry, authentication, or message-delivery semantics.
