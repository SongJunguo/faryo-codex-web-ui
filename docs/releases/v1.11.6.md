# Faryo 1.11.6

Faryo 1.11.6 gives phone-sized New Session sheets back to directory browsing.

- Backend and context controls start collapsed behind a compact Session settings
  summary on phone-sized viewports.
- The summary always reports the effective backend and context window, updates
  immediately after a choice and remains one tap from the full controls.
- Desktop keeps the full launch controls visible, while the directory list owns
  the remaining modal height on both layouts.
- Mobile and desktop browser regressions cover collapsed and expanded geometry,
  selection summaries, directory scrolling and ordinary asset loading.

The clean-room reference review was refreshed against DeepSeek Harness,
YepAnywhere and HAPI. It recommends extracting one generation-aware launch-state
owner before considering the launch sheet as a bounded Preact island; it does
not recommend a whole-Gateway rewrite.

This patch changes Gateway launch presentation only. It does not alter path
authorization, signed directory selections, Codex execution, session ownership,
authentication, message delivery or App Server lifetime.
