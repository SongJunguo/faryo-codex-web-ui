# Faryo 1.11.5

Faryo 1.11.5 makes Activity expansion entirely user-controlled.

- Every Activity batch now defaults collapsed, including running, waiting,
  failed and declined work.
- Attention state and semantic counts remain visible in the collapsed summary.
- A batch opens only after an explicit user click and remains open across later
  live revisions; an ordinary reload returns it to the collapsed default.
- Expanded Activity lists hand continued wheel and touch scrolling to the outer
  conversation when their own top or bottom boundary is reached.
- Browser and unit regressions cover every activity state, lazy detail loading
  and ordinary reload without requiring a hard refresh.

This patch changes presentation only. It does not alter Codex execution,
activity capture, message delivery, authentication or App Server lifetime.
