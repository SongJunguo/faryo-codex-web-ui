# Faryo 1.11.1

Faryo 1.11.1 completes the command and tool timeline introduced in 1.11.0.

## Changes

- Archived App Server threads now use the same persistent Codex App Server
  connection as live sessions. This avoids a competing process and preserves
  the single-writer lifecycle contract.
- Completed activity groups are genuinely lazy: a collapsed group initially
  mounts only its summary row, and materializes individual tool entries after
  the user opens it. This bounds initial DOM work for tool-heavy turns.
- Real-browser coverage now verifies command rows, typed command output,
  on-demand detail, ordinary reload, and asset-revision consistency.

The privacy, authentication, source-only distribution, and tmux compatibility
boundaries documented for Faryo 1.11.0 are unchanged.
